# Agent Memory

This directory stores concise, durable context from previous working sessions for the **4tieQuant Research Agent**.

## How to use this directory

- Check this directory at the start of each session before making project recommendations.
- Record decisions, confirmed facts, unresolved blockers, completed work, and the next agreed action.
- Keep entries concise, dated, and tied to evidence where possible.
- Do not store API keys, passwords, tokens, private credentials, or unnecessary personal data here.
- Do not treat an old memory entry as current when a newer project-state record contradicts it.

## Suggested naming

Use dated files such as:

`YYYY-MM-DD-session-summary.md`

Each file should contain:

- What changed
- Decisions made
- Evidence or tests completed
- Current blockers
- Next action
